# Presenter Packs

One document per person. Each has the same three sections:

1. **The project** — identical in all four. The shared understanding everyone
   needs: what we built, how it works in 60 seconds, the five facts, the numbers.
2. **Your code** — different in each. The files you own, explained, with the
   questions you specifically will be asked.
3. **Your presenting job** — your slide, what to say on it, and what to do when
   something goes wrong.
